Newton Browser

Set up local browser control

Waiting for an MCP client…

1. Install the host

Add Newton Browser to your MCP client

The extension connects only to an MCP host running on this computer.

newton-browser --install <client> can add a supported client configuration for you.

2. Verify

Ask your agent to call browser.status

When an MCP client is running, this page changes to Connected.

Troubleshooting
  • If status stays disconnected, restart your MCP client and load this extension in the same Chrome or Edge profile.
  • Run newton-browser --doctor to check Node, the bounded loopback port range, and extension state.
  • If pairing is required, copy the one-time secret from --doctor into the extension popup. Never put it in MCP configuration.
