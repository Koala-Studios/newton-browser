## Required migration order implied by the inventory

1. Port meaningful direct-session, debugger-port, direct-host, input/dialog, and configured-host negative cases to the shared engine or explicitly record the behavior as unsupported.
2. Port file validation/set-files, dialog/renderer lifecycle, hover/move, resize, and any required page lifecycle behavior before removing old action types.
3. Migrate direct concurrency, hard-crash/guardian, frame churn, input, dialog/renderer, setup/source, and real-task scripts to packed default-engine entrypoints; do not rename direct receipts as packed evidence.
4. Remove the package export and old driver/session/pump/target/result owners, then assert their absence in source and packed artifacts.
5. Rebuild the P00-P14 acceptance matrix from actual public schema/catalog behavior and run the unchanged-tree release sequence only after the missing rows have evidence.
