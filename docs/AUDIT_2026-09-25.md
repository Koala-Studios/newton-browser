## Gaps for dependable unattended worker use

These are not defects in current scope, but a server-hosted worker that operators can watch and help needs them:

1. **Embedding API.** A supported library entry for a host process: start/act/observe/stop plus lifecycle events, without the legacy direct-host exports or spawning the CLI.
2. **Live view.** A bounded frame stream (`Page.startScreencast`) for an operator viewer of the *same* session, instead of a separate browser.
3. **Human takeover in the same session.** Pause agent input, forward operator input, then resume, keeping pages and state; agent commands during takeover fail fast with a specific code.
4. **Authenticator hook.** Optional WebAuthn virtual authenticator credentials supplied by the embedder at session start, and newly created credentials returned to the embedder, never over MCP.
5. **Session defaults.** Viewport, locale and timezone at `session.start`, defaulting to a desktop viewport.
6. **Per-embedder login sources.** Identify a source by name per worker or account (already `sourceId`), with automatic source refresh through the authenticator.
7. **Honest progress under navigation** (D1) and **action feedback that includes overlays** (D4).
